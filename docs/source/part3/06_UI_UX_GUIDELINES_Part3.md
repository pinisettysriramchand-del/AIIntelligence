# 06_UI_UX_GUIDELINES.md — Part 3

## Decision Intelligence Card
Display KPI name, current value, trend, business impact, root cause, evidence, risk, opportunity, recommended action, forecast and confidence.

## Interaction
Users can expand details, open evidence, ask AI about a KPI, compare periods, view related KPIs and add insights to an executive report.

## States
Explicit Loading, Empty, Processing, Success, Warning, Error and Insufficient Evidence states.

## Accessibility
Use keyboard navigation, readable contrast, semantic controls and clear status messaging.
